# Nusuk Helper

Android helper that enters shared Nusuk invite codes on the Nusuk **Keys** screen for you.
Codes only — it does not touch the quiz.

## Download

Get **NusukHelper.apk** from the [Releases](../../releases) page.

## Features

- Floating panel inside Nusuk: pick 10 / 50 / 100 / custom and tap **Start codes**
- Taps "Add another code" after *Congratulations*, clears wrong codes and continues
- Keyboard closes itself after each code; finds its way back to the Keys screen
- Live stats on the panel:

```
⏱ 02:31
✅ Success 100   ❌ Failed 11
🔑 Previous keys: 1325
➕ New keys added: +100
🗝 Total keys now: 1425
Codes 111 · avg 1.36 s per code
```

- Settings: time between codes (0–120 s, ⚡ Fast mode), custom target, 🌙 dim screen while running
- Stops by itself if Nusuk shows a security / "too many" message

## Install

1. Install the APK (allow "install unknown apps").
2. Settings → Accessibility → Installed apps → **Nusuk Helper** → On.
   If it is greyed out: App info → ⋮ → **Allow restricted settings**, then try again.
3. Open Nusuk → Keys screen, use the floating panel.
