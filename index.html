Nusuk Helper

Enters shared Nusuk invite codes on the Keys screen for you

⬇ Download APK
Version 2.1 · Android 7.0+

Features

  • Floating panel inside Nusuk: 10 / 50 / 100 / custom target
  • Taps “Add another code” after Congratulations, skips wrong codes
  • Keyboard closes itself, finds its way back to the Keys screen
  • Settings: time between codes, ⚡ Fast mode, 🌙 dim screen
  • Stops by itself on any security or “too many” message

Install

  1. Download and install the APK (allow “install unknown apps”).
  2. Settings → Accessibility → Installed apps → Nusuk Helper → On.
    Greyed out? App info → ⋮ → Allow restricted settings, then try again.
  3. Open Nusuk → Keys screen and use the floating panel.
